# clinica-sqlite-python
# 🏥 Sistema de Clínica - Python + SQLite

Este projeto é um sistema simples de gerenciamento de pacientes desenvolvido em Python, utilizando SQLite como banco de dados local.

---

## 🚀 Funcionalidades

- Cadastrar pacientes
- Listar pacientes
- Editar informações de pacientes
- Deletar pacientes
- Persistência de dados com SQLite

---

## 🧠 Tecnologias utilizadas

- Python 3
- SQLite (banco de dados local)
- Biblioteca padrão sqlite3
